🌐 3. Native Web Platform APIs (Zero-Dependency Engine)

WebGL 2.0 GPU
Hardware-accelerated GPU pipeline delivering locked 60 FPS graphics across smartphones, tablets, and desktop browsers.
Web Audio API Synth
Procedural sound synthesis: Raga Bhoopali melodies, Tanpura drones, Dholak percussion, and dual-tone train horns without external MP3 files.
Touch Gestures Mobile
Low-latency swipe gesture detector capturing touchstart, touchmove, and touchend vectors for dodging, jumping, and sliding.
HTML5 Canvas 2D 2D Context
Powers procedural texture synthesis in RealisticCharacterTextures.js, creating ballast gravel, WAP-7 liveries, and hazard stripes.
Web Storage localStorage
Persists lifetime high scores, distance records, total laddus, and selected Avatar preference across browser sessions.
Import Maps W3C Standard
Native module resolution for Three.js, guaranteeing fail-safe execution even if raw unbundled source files are loaded.

8.8m electric locomotive with authentic Indian Railways blue livery, chevron hazard striping, pantographs, bogies, cast steel wheels, and Xenon headlight beams.
ICF / LHB Passenger Coaches Procedural 3D
9.2m passenger coaches with corrugated steel roofs, double bogies, rubber gangway bellows, and rear glowing red safety tail-lights.
Auto-Rickshaws & Tempos City Obstacles
Vivid Kelly green & sunshine yellow auto-rickshaws (tuk-tuks) and delivery tempos with safety bumpers and rooftop taxi indicator lights.
Guaranteed Open Track Corridors Clearance Rule
Strict mathematical invariant: maximum 2 stationary trains per wave, leaving exactly 1 track 100% open with a trail of 6 glowing Motichoor Laddus.
